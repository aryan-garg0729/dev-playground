# What Is Git?

Ever had a folder like this?

```
essay.docx
essay-v2.docx
essay-v2-final.docx
essay-v2-final-REALLY-final.docx
```

Now imagine that with a whole project, and five people editing it at once. That's the problem **Git** solves.

Git is a **version control system**: a program that keeps the history of a project. Every time you say so, it takes a **snapshot** of all your files, called a **commit**. With those snapshots you can:

- **see history**: what changed, when, and who changed it
- **undo mistakes**: go back to any earlier snapshot
- **work in parallel**: try an idea on the side without breaking the main version
- **collaborate**: combine your changes with other people's

Git runs **on your own computer**. You'll also hear about **GitHub**: that's a website that stores Git projects online so people can share them. Git first, GitHub later.

Almost every software team in the world uses Git, so this is one of the most useful tools you'll ever learn.
