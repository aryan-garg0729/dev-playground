`console.log` prints its arguments on one line, separated by spaces, and ends the line.

```js
console.log("Oven", 1, "is hot");
// Oven 1 is hot
```

A template literal (backticks) drops values into a string with `${...}`:

```js
const loaves = 12;
console.log(`${loaves} loaves out`);
// 12 loaves out
```
