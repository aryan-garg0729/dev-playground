# Subtree Queries

**Practice:** [Subtree Queries on CSES](https://cses.fi/problemset/task/1137)

## The task

A rooted tree has a value on each node. Either change a node's value, or report the sum of values in a node's subtree.

## Before you code

- Euler tour, plus a Fenwick tree over the `tin` positions.

## Check your approach

Solve it on CSES first, or give it a real try (about 30 minutes) before reading on. The explanation after you answer walks through the full approach.

Node v's value changes from 4 to 9. **What's the Fenwick update?**
