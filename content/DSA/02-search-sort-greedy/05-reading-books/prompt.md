# Reading Books

**Practice:** [Reading Books on CSES](https://cses.fi/problemset/task/1631)

## The task

Two readers must each read all n books. Book i takes `t[i]` minutes for either of them, and nobody can read a book while the other one has it. Minimize the time until both are done.

## Before you code

- Try a few small cases by hand. When does one long book force someone to wait?

## Check your approach

Solve it on CSES first, or give it a real try (about 30 minutes) before reading on. The explanation after you answer walks through the full approach.
