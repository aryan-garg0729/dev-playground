# String Matching

**Practice:** [String Matching on CSES](https://cses.fi/problemset/task/1753)

## The task

Count how many times a pattern occurs in a text. Occurrences may overlap.

## Before you code

- The prefix function on `pattern + "#" + text`, or KMP run directly over the text.

## Check your approach

Solve it on CSES first, or give it a real try (about 30 minutes) before reading on. The explanation after you answer walks through the full approach.

The text is `"aaaa"` and the pattern is `"aa"`. **What's the count?**
