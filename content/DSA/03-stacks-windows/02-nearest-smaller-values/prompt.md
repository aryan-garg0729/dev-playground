# Nearest Smaller Values

**Practice:** [Nearest Smaller Values on CSES](https://cses.fi/problemset/task/1645)

## The task

For each position, find the nearest position to its left with a **strictly** smaller value. Print positions 1-based, or 0 if there's none.

## Before you code

- It's the template from "Monotonic Stack", with 1-based output.

## Check your approach

Solve it on CSES first, or give it a real try (about 30 minutes) before reading on. The explanation after you answer walks through the full approach.
