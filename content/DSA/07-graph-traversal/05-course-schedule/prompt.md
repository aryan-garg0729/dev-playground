# Course Schedule

**Practice:** [Course Schedule on CSES](https://cses.fi/problemset/task/1679)

## The task

n courses have prerequisites ("course a before course b"). Print any valid order to take them, or say it's impossible.

## Before you code

- Kahn's algorithm, as written. The impossible case is the cycle check.

## Check your approach

Solve it on CSES first, or give it a real try (about 30 minutes) before reading on. The explanation after you answer walks through the full approach.

**Which edge should "course a must come before course b" become?**
