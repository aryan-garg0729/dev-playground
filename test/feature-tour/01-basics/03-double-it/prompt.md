Write `double_all(nums)` that returns a new list with every number doubled.

![nums [1, 2, 3] goes through × 2 for each number and becomes a new list [2, 4, 6]](assets/double-flow.svg)

This lesson runs in your browser: **Run** shows the visible checks instantly,
**Submit** grades the hidden ones too. Try a wrong answer first to see a failed
hidden check, then use **Peek** to see its input.
