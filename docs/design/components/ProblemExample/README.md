# ProblemExample

Examples and constraints under the problem statement, in the problem-site convention.

Each example: a `section` heading "Example 1:", then a block with a 2px `border-strong` rule on its left (square corners), 14px left padding, `code-sm` type in `text-secondary`. Lines are **Input:**, **Output:**, and optionally **Explanation:**; the labels use weight 500 in `text`. No boxes or filled backgrounds.

Constraints: a `section` heading "Constraints:" and a bulleted list in `code-sm`, `text-secondary`, 18px indent.

Stack examples with a 16px gap (`space-4`). The consumer provides the inputs, outputs, explanations and constraints from the exercise manifest.
