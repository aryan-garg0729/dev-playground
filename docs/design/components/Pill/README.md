# Pill

Small rounded labels above the problem title: difficulty, topic and reward.

- **Difficulty**: `success` text on `success-soft` for Easy. Medium and Hard are not yet defined; add tokens before using them rather than borrowing `accent` or `danger`.
- **Topic**: `text-secondary` on `surface-raised`.
- **XP**: `game-sm` (pixel) in `accent-text` on `accent-soft`.

All pills use `caption` type (12px, 500), `radius-pill`, 3px × 9px padding, and sit in a wrapping row with a 6px gap.
